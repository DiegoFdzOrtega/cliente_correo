📨 Nexus Mail Pro
Nexus Mail Pro es un cliente de correo electrónico moderno y minimalista desarrollado con un enfoque en la experiencia de usuario (UX) y un diseño SaaS de alta gama. Esta aplicación web permite gestionar flujos de comunicación de manera fluida a través de una interfaz limpia, reactiva y profesional.

🚀 Características Principales
Interfaz SaaS Premium: Diseño basado en Plus Jakarta Sans con un sistema de colores balanceado y soporte para Modo Oscuro.

Gestión de Carpetas: Soporte funcional para Inbox (Recibidos), Enviados, Destacados (Starred) y Papelera (Trash).

Composición en Tiempo Real: Sistema de redacción de correos mediante una ventana emergente (Composer) que permite enviar mensajes sin perder el contexto de la bandeja de entrada.

Búsqueda Inteligente: Filtrado dinámico de mensajes por remitente o asunto directamente desde la barra de búsqueda.

Contadores Dinámicos: Indicadores en tiempo real de correos no leídos y mensajes destacados.

Diseño Adaptativo: Estructura de tres paneles (Navegación, Lista, Visor) optimizada para flujos de trabajo profesionales.

🛠️ Tecnologías Utilizadas
HTML5: Estructura semántica para una mejor accesibilidad.

CSS3: Variables CSS (Custom Properties), Flexbox, Grid y efectos de Glassmorphism.

JavaScript (Vanilla): Lógica de estado global para la gestión de datos, filtrado y manipulación del DOM sin dependencias externas.

Google Fonts: Implementación de tipografía de alta legibilidad.

📖 Instrucciones de Uso
Instalación: No requiere dependencias. Simplemente descarga el archivo index.html.

Ejecución: Abre el archivo en cualquier navegador moderno (Chrome, Edge, Brave, Safari).

Interacción:

Haz clic en los correos para leerlos.

Usa la estrella (★) para mover correos a la carpeta de Destacados.

Usa el botón Eliminar en el visor para mover correos a la Papelera.

Pulsa Redactar para simular el envío de un nuevo correo.
